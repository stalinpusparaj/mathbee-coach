# Asset manifest

_Generated by `npm run docs:coverage` from `src/assets/sprites.generated.json` and `src/assets/manifest.ts`._

## Provenance

- **Raster sprites** were cut automatically (`tools/extract_assets.py`) from the eleven transparent asset sheets supplied in the project root (`ChatGPT Image Sep 27, 2026, 07_19_34 PM-1.png` … `-11.png`). Each object was separated by its alpha channel, cropped, downsized to ≤360 px and saved as WebP with transparency preserved. Whole sheets are never shown.
- **`garden_scenery`** is a decorative crop of the supplied garden-map concept image (`download/ChatGPT_Image_…194655.jpg`) with the logo, text and buttons cut away. It is used only as the welcome-screen backdrop, never as an interactive surface.
- **Not used:** the 22 other images in `download/` are claymation-style concept screens with a *robot* bee, lives and scores, and a Sunday-first calendar. They conflict with the one-consistent-bee and no-lives requirements, so they were used for reference only. The orchard/picnic concept screen (`…194654.jpg` / root `07_01_51 PM.png`) is a layout reference only.
- **Optional generated art** (`tools/generate_art.mjs` → `tools/process_generated.py`, Google Gemini image model): listed below with source `generated: <model> (<date>)`. Prompts are in `tools/art-brief.json`; raw outputs and prompts are kept in `art-generated/raw/`.
- **One bee:** the round storybook bee (`bee`, sheet 1) is the single mascot throughout.
- Mathematical content is never taken from art: all quantities, clocks, calendars, shapes, number lines, ten-frames and base-ten blocks are drawn in code from data.
